## 🎤 WICHTIGSTE AUSSAGEN PRO FOLIE

### Folie 1: Titel
```
📢 "Guten Tag! Wir sind [Name1] und [Name2]. 
   Wir präsentieren unsere Praxisarbeit zum Thema 'Evil Twin' 
   - einer der gefährlichsten WLAN-Attacken im echten Leben.
   
   Gleich werden wir zeigen: Wie funktioniert es? 
   Warum ist es so gefährlich? Und vor allem: 
   Wie schützen wir uns davor?"
```

### Folie 2: Einleitung
```
📢 "Evil Twin ist nicht theoretisch - es passiert JETZT.
   An Flughäfen, in Cafés, auf Konferenzen.
   Ein Hacker erschafft einfach ein WLAN mit gleichem Namen
   wie das echte WLAN. Clients verbinden sich freiwillig.
   Und der Hacker sitzt als MITM (Man-in-the-Middle)
   und sieht ALLES zwischen Client und Internet.
   
   Das ist die Genialität: Keine Hacker-Fertigkeiten nötig,
   nur Social Engineering + einfache Technik."
```

### Folie 3: Definition
```
📢 "Ein Evil Twin ist ein Rogue Access Point.
   SSID ist identisch zu echtem AP.
   
   WICHTIGER UNTERSCHIED:
   - WiFi Cracking: Brute-Force Passwort (Hacker sitzt außen)
   - Evil Twin: Hacker sitzt IN DER MITTE (viel mächtiger!)
   
   RESULTAT: Hacker ist wie ein Netzwerk-Admin für diesen Client.
   Sieht alles, kann alles manipulieren, kann alles stehlen."
```

### Folie 4: Angriffsvektoren
```
📢 "Es gibt zwei Angriffsarten:

   PASSIV (schwer zu detektieren):
   - Packet Sniffing: Unverschlüsselte Daten abfangen
   - Session Hijacking: Cookies klauen → Account Takeover
   - Credential Harvesting: Passwörter sammeln
   
   AKTIV (manipulativ):
   - DNS Spoofing: Fake Websites anzeigen (Phishing!)
   - SSL Stripping: HTTPS zu HTTP herunterstufeln
   - Malware-Injection: Schadsoftware unterwegs injizieren
   
   RESULTAT: Hacker kann Daten klauen UND ändern. Total Power."
```

### Folie 5: Implementierung
```
📢 "Technisch ist Evil Twin SEHR EINFACH.
   
   HARDWARE:
   - Beliebiger Laptop/Raspberry Pi
   - WLAN-Adapter (im Monitor-Modus)
   
   SOFTWARE:
   - hostapd: Erstellt den Access Point
   - dnsmasq: Vergibt IP-Adressen
   - aircrack-ng: Scannt und analysiert
   - Wireshark: Zeigt den Traffic
   
   BARRIERE ZUM ANGRIFF: Sehr niedrig!
   Alles OpenSource, kostenlos, dokumentiert.
   Ein interessierter Hacker braucht vielleicht 1 Stunde Setup."
```

### Folie 6: LIVE DEMO ⭐
```
📢 "Jetzt wird es praktisch!
   
   [WIRESHARK ÖFFNEN - alle sehen den Traffic]
   
   Sie sehen hier einen simulierten Angreifer (links)
   und einen ahnungslosen Client (rechts).
   Der Client verbindet sich mit "FreeAirport_Wifi".
   
   Was Sie nicht sehen können: Der Traffic wird DURCH 
   meinen Laptop geleitet - ich sitze MITM.
   
   Jetzt öffnet der Client eine unverschlüsselte Website...
   
   [ZEIGE IN WIRESHARK: HTTP Passwörter sichtbar]
   
   BOOM! Da ist das Passwort. In KLARTEXT. 
   
   Das ist warum Evil Twin so gefährlich ist!"
```

### Folie 7: Schutzmassnahmen
```
📢 "Wie schützen wir uns?
   
   BEST PRACTICE - Mehrschichtige Defense:
   
   1. VPN nutzen: Verschlüsselt ALLES zwischen dir 
      und VPN-Server. Evil Twin sieht nur chinesische Zeichen.
   
   2. HTTPS erzwingen: Zertifikat validieren.
   
   3. Vertrauen sein WLAN überprüfen: Starbucks fragen!
   
   FÜR ADMINISTRATOREN:
   - 802.1X Authentifizierung (nur registrierte Clients)
   - WPA3 statt WPA2 (neuere Sicherheit)
   - Rogue AP Detection (erkennen von Evil Twins)
   
   KEY POINT: Kombination aller Massnahmen = Sicherheit"
```

### Folie 8: Legale Aspekte
```
📢 "WARNUNG: Das ist WICHTIG.
   
   Evil Twin OHNE Genehmigung = STRAFBAR.
   Unbefugter Zugriff, Datendiebstahl.
   Straffreihheit: Bis zu 10 Jahren Gefängnis!
   
   ABER: Wo es LEGAL ist:
   - Penetration Testing (mit schriftlicher Genehmigung!)
   - Forschung & Bildung (isolierte Labore)
   - Bug Bounty Programme
   - Responsible Disclosure
   
   UNSERE POSITION:
   Diese Präsentation ist für BILDUNGSZWECKE.
   Wir zeigen die Schwäche um sie zu verbessern,
   nicht um Schaden anzurichten."
```

### Folie 9: Quellen
```
📢 "Alles was wir gezeigt haben basiert auf vertrauenswürdigen 
   Quellen - OWASP, IEEE, NIST, Kali Linux.
   
   Wenn Sie mehr erfahren möchten:
   - OWASP.org für Sicherheits-Testing
   - Kali Linux für praktische Tools
   - IEEE 802.11 für Wireless-Standards
   
   Fragen? Gerne!"

## ❓ HÄUFIGSTE FRAGEN (Was Betreuer fragen könnten)

### Q1: "Ist Evil Twin kompliziert?"
```
A: "Nein! Die Barriere ist sehr niedrig.
   Ein interessierter Hacker braucht vielleicht 1-2 Stunden.
   Darum ist es so verbreitet."
```

### Q2: "Warum ist VPN besser als nur HTTPS?"
```
A: "HTTPS schützt den Inhalt. VPN schützt ALLES:
   - Inhalt
   - Metadaten
   - DNS Queries
   - IP Adressen
   
   VPN = totale Verschlüsselung vom Anfang bis zum Endes."
```

### Q3: "Kann man Evil Twin wirklich nicht detektieren?"
```
A: "Schwierig aber nicht unmöglich!
   Tools wie Kismet können mehrere APs mit gleicher SSID
   erkennen. Aber für durchschnittliche Nutzer: sehr schwer."
```

### Q4: "Ist unsere Demo ethisch vertretbar?"
```
A: "Ja! Isoliertes Labor, keine echten Clients, Bildungszweck.
   Wir zeigen die Schwäche um sie zu verbessern."
